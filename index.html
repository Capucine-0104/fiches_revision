Algèbre et analyse

Le socle : à connaître sans hésiter, parce que tout le reste s'appuie dessus.

Second degré

Première

À retenir

  • DiscriminantΔ = b² − 4ac
  • RacinesΔ > 0 : x = (−b ± √Δ) / 2a  ·  Δ = 0 : x = −b / 2a  ·  Δ < 0 : aucune racine réelle
  • Forme canoniquea(x − α)² + β avec α = −b / 2a et β = f(α)
  • Factorisationa(x − x₁)(x − x₂)
  • Somme, produitx₁ + x₂ = −b / a  ·  x₁x₂ = c / a
  • Signe du trinômesigne de a à l'extérieur des racines, signe de −a entre elles

Réflexes

  • Une racine « évidente » (0, 1, −1) donne tout de suite l'autre avec la somme ou le produit.
  • Le sommet de la parabole est (α ; β) : c'est l'extremum de la fonction.
  • Une équation de degré 4 en x⁴ ou en eˣ se ramène au second degré par changement d'inconnue.

Suites

Terminale

À retenir

  • Arithmétique, raison ruₙ₊₁ = uₙ + r  ·  uₙ = u₀ + n·r
  • Géométrique, raison quₙ₊₁ = q·uₙ  ·  uₙ = u₀·qⁿ
  • Somme arithmétiqueu₀ + … + uₙ = (n + 1)(u₀ + uₙ) / 2
  • Somme géométrique (q ≠ 1)1 + q + … + qⁿ = (1 − qn+1) / (1 − q)
  • Limite de qⁿq > 1 : +∞  ·  −1 < q < 1 : 0  ·  q ≤ −1 : pas de limite
  • Arithmético-géométriqueuₙ₊₁ = a·uₙ + b (a ≠ 1) : on pose ℓ = b / (1 − a), alors vₙ = uₙ − ℓ est géométrique de raison a
  • Convergence monotonecroissante et majorée ⇒ convergente
  • Bernoulli(1 + a)ⁿ ≥ 1 + na pour a ≥ 0

Réflexes

  • Récurrence : initialisation, hérédité (on suppose P(n), on prouve P(n+1)), conclusion écrite.
  • Forme indéterminée : factoriser par le terme dominant (n², qⁿ…).
  • Une suite avec sin n ou (−1)ⁿ : penser à l'encadrement ou à la comparaison.
  • Seuil : on le trouve avec une boucle while, ou avec ln si la suite est géométrique.
def seuil(M):
    n, u = 0, 1.0
    while u < M:
        u = 1.5 * u      # uₙ₊₁ = 1,5 · uₙ
        n += 1
    return n             # plus petit n tel que uₙ ≥ M

Limites et continuité

Terminale

À retenir

  • Polynôme en ±∞même limite que son terme de plus haut degré
  • Fraction rationnelle en ±∞même limite que le rapport des termes de plus haut degré
  • Croissances comparéeseˣ / xⁿ → +∞  ·  ln x / xⁿ → 0 (en +∞)  ·  xⁿeˣ → 0 (en −∞)  ·  x ln x → 0 (en 0⁺)
  • Asymptoteslim f = ℓ en ±∞ ⇒ y = ℓ  ·  lim f = ±∞ en a ⇒ x = a
  • Compositionlimx→a u(x) = b et limX→b f(X) = c ⇒ limx→a f(u(x)) = c
  • Théorème des valeurs intermédiairesf continue sur [a ; b], k entre f(a) et f(b) ⇒ f(x) = k a au moins une solution ; une seule si f est strictement monotone

Réflexes

  • Quatre formes indéterminées : ∞ − ∞, 0 × ∞, ∞ / ∞, 0 / 0. On transforme l'écriture (factoriser, conjugué).
  • Dérivable ⇒ continue, mais pas l'inverse (|x| en 0).
  • Dans un tableau de variations, noter les limites aux bornes.
  • La dichotomie encadre une solution : un algorithme classique à savoir écrire en Python.

Dérivation et convexité

Première · Terminale

À retenir

  • Fonctions usuelles(xⁿ)′ = n·xn−1  ·  (1/x)′ = −1/x²  ·  (√x)′ = 1 / 2√x  ·  (eˣ)′ = eˣ  ·  (ln x)′ = 1/x  ·  sin′ = cos  ·  cos′ = −sin
  • Produit, quotient(uv)′ = u′v + uv′  ·  (u/v)′ = (u′v − uv′) / v²
  • Composées(uⁿ)′ = n·u′·un−1  ·  (eu)′ = u′·eu  ·  (ln u)′ = u′ / u  ·  (√u)′ = u′ / 2√u
  • Cas affine[f(ax + b)]′ = a·f′(ax + b)
  • Tangente en ay = f′(a)(x − a) + f(a)
  • Convexitéf″ ≥ 0 : convexe (courbe au-dessus de ses tangentes)  ·  f″ ≤ 0 : concave  ·  inflexion si f″ s'annule en changeant de signe

Réflexes

  • Signe de f′ ⇒ variations. Factoriser f′ pour lire son signe.
  • eˣ est toujours strictement positif : le signe de f′ vient de l'autre facteur.
  • Une inégalité du type eˣ ≥ 1 + x se prouve par la convexité (position par rapport à la tangente).
  • Un extremum local se cherche là où f′ s'annule et change de signe.

Exponentielle et logarithme népérien

Première · Terminale

À retenir

  • Exponentielleea+b = eᵃ·eᵇ  ·  e−a = 1 / eᵃ  ·  (eᵃ)ⁿ = ena  ·  eˣ > 0
  • Résolutioneˣ = k ⇔ x = ln k (k > 0)  ·  eˣ ≤ k ⇔ x ≤ ln k
  • Logarithmeln(ab) = ln a + ln b  ·  ln(a/b) = ln a − ln b  ·  ln(aⁿ) = n·ln a
  • Réciproquesln(eˣ) = x  ·  eln x = x (x > 0)  ·  ln 1 = 0  ·  ln e = 1
  • Inégalitéseˣ ≥ 1 + x  ·  ln x ≤ x − 1
  • Seuil géométriqueqⁿ ≥ M ⇔ n ≥ ln M / ln q si q > 1

Réflexes

  • ln n'est défini que pour un argument strictement positif : vérifier le domaine avant de l'écrire.
  • ln(a + b) n'est pas ln a + ln b.
  • Passer au ln dans une inéquation garde le sens (ln est croissante).
  • Si 0 < q < 1, ln q est négatif : le sens s'inverse en divisant par ln q.

Trigonométrie

Première · Terminale

À retenir

  • Relation fondamentalecos²x + sin²x = 1  ·  180° = π rad
  • Parité, périodecos paire, sin impaire, toutes deux 2π-périodiques
  • Angles liéscos(π − x) = −cos x  ·  sin(π − x) = sin x  ·  cos(π/2 − x) = sin x
  • Équation cos x = cos ax = a + 2kπ ou x = −a + 2kπ
  • Équation sin x = sin ax = a + 2kπ ou x = π − a + 2kπ
  • Addition (vu en expertes)cos(a + b) = cos a cos b − sin a sin b  ·  sin(a + b) = sin a cos b + cos a sin b
  • Duplicationcos 2a = 2cos²a − 1 = 1 − 2sin²a  ·  sin 2a = 2 sin a cos a
x0π/6π/4π/3π/2
cos x1√3/2√2/21/20
sin x01/2√2/2√3/21

Réflexes

  • Les équations trigonométriques donnent une famille de solutions : toujours préciser « k ∈ ℤ », puis garder celles de l'intervalle demandé.
  • Pour une limite avec sin ou cos, l'encadrement −1 ≤ sin x ≤ 1 est le premier réflexe.
  • Étudier la parité et la période d'abord réduit l'intervalle d'étude.
  • Les formules d'addition et de duplication resservent avec les complexes (linéarisation).

Primitives et équations différentielles

Terminale

À retenir

  • Primitives usuellesxⁿ → xn+1 / (n+1) (n ≠ −1)  ·  1/x² → −1/x  ·  1/√x → 2√x  ·  1/x → ln x (x > 0)  ·  eˣ → eˣ  ·  cos → sin  ·  sin → −cos
  • Formes composéesu′uⁿ → un+1 / (n+1)  ·  u′ / u → ln|u|  ·  u′eu → eu  ·  u′ / √u → 2√u
  • Unicitédeux primitives d'une même fonction diffèrent d'une constante
  • y′ = ayy(x) = C·eax ; avec y(x₀) = y₀ : C = y₀·e−ax₀
  • y′ = ay + b (a ≠ 0)y(x) = C·eax − b / a
  • y′ = ay + fsolution générale = une solution particulière + C·eax

Réflexes

  • Reconnaître la forme u′ × f(u) avant de chercher plus compliqué.
  • Vérifier une primitive en la dérivant : c'est rapide et sûr.
  • Une équation différentielle modélise une évolution (décroissance, refroidissement, charge d'un condensateur) : la constante C vient de la condition initiale.

Calcul intégral

Terminale

À retenir

  • Définition∫ab f(x) dx = F(b) − F(a), F primitive de f
  • Linéarité, Chasles∫(αf + βg) = α∫f + β∫g  ·  ∫ac f = ∫ab f + ∫bc f
  • Positivité, croissancea ≤ b et f ≥ 0 ⇒ ∫ab f ≥ 0  ·  f ≤ g ⇒ ∫f ≤ ∫g
  • Valeur moyenneμ = 1 / (b − a) · ∫ab f(x) dx
  • Aire entre deux courbes∫ab (f − g) dx si f ≥ g sur [a ; b]
  • Intégration par parties∫ab u′v = [uv]ab − ∫ab uv′
Exemple : ∫₀¹ x·eˣ dx   avec u′ = eˣ, v = x
  = [x·eˣ]₀¹ − ∫₀¹ eˣ dx = e − (e − 1) = 1

Réflexes

  • Intégration par parties : choisir v pour que v′ soit plus simple que v (v = x, v = ln x).
  • Une aire se compte en unités d'aire, et seulement avec une fonction positive (sinon séparer les intervalles).
  • Pour encadrer une intégrale, encadrer d'abord la fonction puis intégrer l'inégalité.
  • Une suite d'intégrales Iₙ se traite souvent par intégration par parties, pour obtenir une relation entre Iₙ et Iₙ₊₁.

Géométrie

Le plan (Première) puis l'espace (Terminale) : le produit scalaire est l'outil commun.

Produit scalaire et géométrie repérée dans le plan

Première

À retenir

  • Produit scalaireu·v = ‖u‖·‖v‖·cos θ = xx′ + yy′
  • Orthogonalitéu ⊥ v ⇔ u·v = 0
  • Norme, distance‖u‖ = √(x² + y²)  ·  AB = √((xB − xA)² + (yB − yA)²)
  • Al-KashiBC² = AB² + AC² − 2·AB·AC·cos(Â)
  • Droiteax + by + c = 0, vecteur normal (a ; b), vecteur directeur (−b ; a)
  • Cercle(x − a)² + (y − b)² = r²

Réflexes

  • Pour prouver une orthogonalité : calculer le produit scalaire avec les coordonnées.
  • L'ensemble des points M tels que MA·MB = 0 est le cercle de diamètre [AB].
  • Un vecteur normal donne directement l'équation cartésienne de la droite.

Géométrie dans l'espace

Terminale

À retenir

  • Coplanarité, basetrois vecteurs non coplanaires forment une base de l'espace
  • Produit scalaireu·v = xx′ + yy′ + zz′  ·  ‖u‖ = √(x² + y² + z²)
  • Droite (A, u)x = xA + t·a  ·  y = yA + t·b  ·  z = zA + t·c  (t ∈ ℝ)
  • Plan, vecteur normaln(a ; b ; c) normal au plan ⇒ ax + by + cz + d = 0
  • Parallélisme, orthogonalitéplans parallèles ⇔ normaux colinéaires  ·  droites orthogonales ⇔ vecteurs directeurs orthogonaux
  • Projeté orthogonal H de M sur un planle point du plan le plus proche de M : distance = MH

Réflexes

  • Intersection droite et plan : remplacer x, y, z de la droite dans l'équation du plan, puis résoudre en t.
  • Équation d'un plan : trouver un vecteur normal (deux produits scalaires nuls avec deux vecteurs du plan), puis calculer d avec un point.
  • Pour la distance d'un point à un plan : projeté orthogonal H, puis longueur MH.

Compter, puis calculer des probabilités : la suite logique, et un terrain très utilisé en informatique.

Combinatoire et dénombrement

Terminale

À retenir

  • p-uplets (avec répétition)nᵖ
  • Permutationsn!
  • Arrangements (ordre compte)n! / (n − p)!
  • Combinaisons (ordre ne compte pas)C(n, p) = n! / (p!·(n − p)!)
  • PropriétésC(n, p) = C(n, n − p)  ·  C(n, p) + C(n, p+1) = C(n+1, p+1)
  • Parties d'un ensembleun ensemble à n éléments a 2ⁿ parties : ΣC(n, k) = 2ⁿ
  • Binôme de Newton(a + b)ⁿ = Σk=0n C(n, k)·aᵏ·bⁿ⁻ᵏ
from math import comb, factorial
comb(10, 3)      # 120
factorial(5)     # 120

Réflexes

  • Deux questions pour choisir la formule : l'ordre compte-t-il ? Peut-on répéter un élément ?
  • Principe multiplicatif : une succession de choix indépendants se multiplie.
  • Un « au moins un » se calcule souvent par le contraire (tout moins « aucun »).

Probabilités conditionnelles et indépendance

Première

À retenir

  • Probabilité conditionnellePA(B) = P(A ∩ B) / P(A)
  • Probabilité d'une intersectionP(A ∩ B) = P(A)·PA(B)
  • Probabilités totalesP(B) = P(A ∩ B) + P(A ∩ B)
  • IndépendanceA et B indépendants ⇔ P(A ∩ B) = P(A)·P(B)
  • Arbre pondéréon multiplie le long d'une branche, on additionne les branches qui mènent à l'événement

Réflexes

  • Dessiner l'arbre dès que l'énoncé parle de « sachant que ».
  • La somme des probabilités des branches issues d'un même nœud vaut 1.
  • Pour « inverser » une probabilité conditionnelle (de PA(B) vers PB(A)), repasser par P(A ∩ B).
  • Incompatibles et indépendants sont deux notions différentes.

Variables aléatoires, loi binomiale, concentration

Première · Terminale

À retenir

  • Espérance, varianceE(X) = Σ xᵢpᵢ  ·  V(X) = E(X²) − E(X)²  ·  σ = √V(X)
  • Transformation affineE(aX + b) = aE(X) + b  ·  V(aX + b) = a²V(X)
  • SommeE(X + Y) = E(X) + E(Y)  ·  V(X + Y) = V(X) + V(Y) si X et Y indépendantes
  • Loi binomiale B(n, p)P(X = k) = C(n, k)·pᵏ·(1 − p)ⁿ⁻ᵏ
  • Paramètres de B(n, p)E(X) = np  ·  V(X) = np(1 − p)
  • Bienaymé-TchebychevP(|X − E(X)| ≥ δ) ≤ V(X) / δ²
  • Concentration de la moyenne MₙP(|Mₙ − μ| ≥ δ) ≤ σ² / (nδ²)
from math import comb
def binom(n, k, p):
    return comb(n, k) * p**k * (1 - p)**(n - k)

Réflexes

  • Reconnaître un schéma de Bernoulli : n épreuves identiques, indépendantes, deux issues.
  • « Au moins un succès » : P(X ≥ 1) = 1 − (1 − p)ⁿ.
  • Taille d'échantillon : l'inégalité de concentration donne un n qui garantit une précision δ.
  • La loi des grands nombres dit que la moyenne observée se rapproche de l'espérance quand n grandit.

Extension : maths expertes

Ces trois chapitres ne sont pas dans la spécialité seule. Si tu ne les as pas suivis, ils méritent une vraie lecture : complexes, matrices et arithmétique reviennent très vite en informatique et en sciences de l'ingénieur.

Nombres complexes

Expertes

À retenir

  • Forme algébriquez = a + ib, i² = −1
  • Conjugué, modulez = a − ib  ·  z·z = |z|² = a² + b²  ·  |z| = √(a² + b²)
  • Forme trigonométriquez = |z|(cos θ + i sin θ) = |z|·eiθ
  • Produit, puissance|zz′| = |z|·|z′|  ·  arg(zz′) = arg z + arg z′ [2π]  ·  arg(zⁿ) = n·arg z  ·  arg(z) = −arg z
  • Moivre(cos θ + i sin θ)ⁿ = cos nθ + i sin nθ
  • Eulercos θ = (eiθ + e−iθ) / 2  ·  sin θ = (eiθ − e−iθ) / 2i
  • Second degré, Δ < 0z = (−b ± i√(−Δ)) / 2a
  • Racines n-ièmes de l'unitée2ikπ/n, k = 0, 1, …, n − 1

Réflexes

  • Forme algébrique pour les sommes, forme exponentielle pour les produits et les puissances.
  • Pour diviser : multiplier haut et bas par le conjugué du dénominateur.
  • Les formules d'Euler servent à linéariser cosⁿ et sinⁿ avant d'intégrer.
  • Un argument se donne modulo 2π ; vérifier le quadrant avant de conclure.

Matrices et graphes

Expertes

À retenir

  • Produitcoefficient (i, j) de AB = Σk aᵢₖ·bₖⱼ (ligne i de A par colonne j de B)
  • Non commutatifAB ≠ BA en général
  • InverseA·A⁻¹ = A⁻¹·A = I
  • Cas 2 × 2A = (a b ; c d) est inversible ⇔ ad − bc ≠ 0, et alors A⁻¹ = 1/(ad − bc) · (d −b ; −c a)
  • Système AX = Bsi A est inversible, X = A⁻¹B
  • Suite de matricesXₙ₊₁ = A·Xₙ ⇒ Xₙ = Aⁿ·X₀
  • Suite avec terme constantXₙ₊₁ = A·Xₙ + B : l'état stable vérifie X = A·X + B, donc X = (I − A)⁻¹B si I − A est inversible
  • Graphe, adjacencecoefficient (i, j) de Aⁿ = nombre de chaînes de longueur n de i à j
  • Graphe probabilisteπₙ₊₁ = πₙ·P ; état stable π = π·P, de somme 1

Réflexes

  • Vérifier les dimensions avant un produit : (m × n) par (n × p) donne (m × p).
  • La calculatrice ou NumPy (numpy.linalg) fait les puissances et les inverses ; l'important est de savoir poser le modèle.
  • Chaque ligne d'une matrice de transition somme à 1 (selon la convention du cours).

Divisibilité, congruences, PGCD

Expertes

À retenir

  • Division euclidiennea = bq + r avec 0 ≤ r < b
  • Congruencea ≡ b [n] ⇔ n divise a − b ⇔ même reste dans la division par n
  • Compatibilitéles congruences se somment, se multiplient et se mettent à la puissance
  • Algorithme d'EuclidePGCD(a, b) = PGCD(b, r), r reste de a par b
  • Identité de BézoutPGCD(a, b) = d ⇒ il existe u, v entiers avec au + bv = d
  • Théorème de Bézouta et b premiers entre eux ⇔ il existe u, v entiers avec au + bv = 1
  • Gaussa | bc et PGCD(a, b) = 1 ⇒ a | c
  • Inverse modulo na est inversible modulo n ⇔ PGCD(a, n) = 1
  • Petit théorème de Fermatp premier, p ne divise pas a ⇒ ap−1 ≡ 1 [p]
from math import gcd
gcd(84, 30)        # 6
pow(7, -1, 26)     # 15, car 7 × 15 = 105 = 4 × 26 + 1
pow(3, 100, 17)    # 13 (puissance modulaire rapide)

Réflexes

  • Pour un reste d'une grande puissance : chercher la période des restes, ou utiliser Fermat.
  • Pour prouver une divisibilité : disjonction de cas sur les restes modulo n.
  • Une équation ax + by = c n'a de solution entière que si PGCD(a, b) divise c.
  • Ces notions fondent le chiffrement affine et RSA, au programme de beaucoup de cours de sécurité informatique.
